# PLAYFIELD — UI・自然文検索・3D地形ビュー（2026-10）

## 目指す体験
「どんな一日を過ごしたいか」を自然文で入力し、候補をコース名・横長写真・料金目安・事実に基づくおすすめ理由から選ぶ。
オリジナルのストリートゴルフ表現：バターイエロー／ペールブルー／コーラル、雑誌的タイポグラフィ、実際のルールを示す4枚のステッカー、コース紹介の吹き出し。Malbonブランドのキャラクター・ロゴ・意匠を複製しない。

## 自然文検索
- `web/lib/course-matcher.js`：エリアと出発地、日付、予算（約〜厳格な上限）、評価、同行者、景観、コース種別などの意図を抽出し、GORAの実データとの一致度で順位付け
- コース名・紹介文は直接・部分・2-gram類似で照合。辞書にない表現はそのまま名称・説明文の文字列検索候補に使う
- 一致する理由だけ表示する。根拠のない「AI度」「相性98%」は作らない
- 条件に合う候補が0件のときは予算、次にエリアを緩和し、緩和したことを明示する
- 出発地は近隣都道府県の推奨に使用。**正確な車移動時間は計算しない**
- 日付は `web/assets/round-date.js` で解釈。**空き枠の照会や日付固有の実料金はしていない**
- 辞書ベースなので、「あらゆる文章の意図を完全理解するAI」ではない。辞書の拡張は `INTENTS` と `EVIDENCE` を変更する

## 服装ステッカー
- `web/lib/dress-stickers.js` をSSR詳細に組み込み
- ジャケット／襟・トップス／サンダル／シューズを4枚のアイコンで表示。禁止や着用必須はAPI解析で根拠がある場合のみ。未知・未記載の項目は必ず「要確認」
- サマリだけでなく元の服装規定全文を併記する
- ランディング一覧では原文がないため「規定の言及あり」に留め、着用自由は決して断定しない

## 立体地形
- コース座標が日本の範囲内で取得できた場合のみ、SSR詳細に「この場所を、立体で見る」を表示
- `web/assets/terrain-view.js` がユーザーのクリック後に MapLibre GL JS を読み込む
- OpenFreeMap（OpenStreetMap ベースの地図）と Mapterhorn（実測標高に基づく地形タイル）を使用
- MapLibre GL JS: https://maplibre.org/maplibre-gl-js/
- OpenFreeMap: https://openfreemap.org/
- Mapterhorn: https://mapterhorn.com/attribution/
- マップ上のコースピンはAPIの緯度経度。**各ホールの正確な形状を表した3Dコースモデルではない**
- WebGLが使えない端末には通常地図の外部リンクを表示。地形データが失敗しても「3D表示できた」とは断言しない

## 本番確認
- `web` で `npm test` を実行
- 検索：`?q=大阪から1時間で初心者と、景色がいい場所。土日1.3万円以内`
- 地域：`?q=熊本で海を感じたい、景色も大事`
- 日付：`?q=10月18日、大阪で友人と`
- 詳細：`/course/90107` （データが存在する場合）
- 詳細のジャケット・サンダルステッカーの内容、服装原文、立体地形のOpenFreeMap / Mapterhornの帰属、楽天GORA予約導線
- 自動用品アフィリエイトの初回同期は別途ロリポップ固定IPから `worker/scripts/run_ichiba_affiliate.sh --dry-run` → 正常なら本実行。現段階ではスクリプトを配置しただけで、スケジュール稼働済みとは主張しない

## データ品質・法的注意
- 楽天GORAのロゴ／画像はAPI・パートナー規約の範囲で掲載し、必要に応じて利用許諾を再確認
- 短い検索理由はコースの紹介文や数値だけから生成
- 季節別用品とアフィリエイトリンクはAPI実行時に取得するため、価格・在庫の鮮度を保証しない
